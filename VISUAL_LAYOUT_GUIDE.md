## Key Breakpoint Events

| Width | Event | Change |
|-------|-------|--------|
| **320px** | Mobile start | Minimal everything |
| **425px** | Large mobile | Better proportions |
| **640px** | Mobile edge | Featured items go horizontal |
| **768px** | Tablet start | 2-column grids begin |
| **900px** | Transition | Hero becomes 2-column |
| **1024px** | Tablet landscape | Nav fully visible, 3-col grids |
| **1440px** | Desktop | Premium layout, full nav |
| **2560px** | 4K | Oversized, max-width active |
